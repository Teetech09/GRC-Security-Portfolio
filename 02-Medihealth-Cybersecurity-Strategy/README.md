
# MediHealth Clinic Cybersecurity Strategy

## Project Overview

This project develops a cybersecurity strategy for MediHealth Clinic, a fictional healthcare provider in Nigeria with 50 employees.

The clinic uses an electronic health record (EHR) system to manage sensitive patient information, including personal details, medical histories, and insurance information.

The scenario describes an EHR server hardware failure that disrupted access, repeated phishing attempts, and weaknesses in account security, software maintenance, data protection, and physical security.

## Project Objective

Develop a practical, prioritised cybersecurity strategy that protects patient information, supports reliable access to clinical systems, and reduces risks to patient care.

## Scope

The project covers:

- Phishing awareness and a proposed simulation plan.
- Password security and individual user accountability.
- Multi-factor authentication implementation planning.
- Healthcare threats and vulnerabilities.
- Risk assessment and prioritised treatment.
- Backup, recovery, and incident response planning.

## Approach

1. Document the scenario, scope, and baseline security posture.
2. Identify important assets, threats, and vulnerabilities.
3. Assess and prioritise risks.
4. Develop policies, awareness materials, and implementation plans.
5. Assemble a cybersecurity strategy report and presentation.
6. Document lessons learned and assessment limitations.
