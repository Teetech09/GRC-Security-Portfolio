R003 – Misconfigured Cloud Storage Permissions: Risk Validation

This folder is reserved for evidence used to validate the identified cloud storage risk.

Planned Evidence
- EV011 – Cloud storage bucket access configuration.
- EV012 – Bucket policy and Access Control List (ACL).
- EV013 – Cloud access logs.

Purpose
To determine whether cloud storage resources are improperly exposed to unauthorised users or the public due to excessive permissions or misconfigured access policies.

No actual organisational evidence is included. This is a simulated portfolio project.
