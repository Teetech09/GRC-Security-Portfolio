 R006 – Third-Party Payment Processor Exposure: Risk Validation

This folder is reserved for evidence used to validate the identified third-party security risk.

Planned Evidence
- EV029 – Third-party vendor security assessment.
- EV030 – Vendor compliance and certification documentation, such as PCI DSS Attestation of Compliance (AoC) or SOC 2 reports.
- EV031 – Vendor security incidents and breach records.

Purpose
To assess the security and compliance posture of the organisation's third-party payment processor and identify risks that could affect the confidentiality, integrity and availability of payment information.

No actual organisational evidence is included. This is a simulated portfolio project.
