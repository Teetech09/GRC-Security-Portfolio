R008 – Unpatched System Vulnerabilities: Risk Validation

This folder is reserved for evidence used to validate the identified vulnerability management risk.

Planned Evidence
- EV041 – Vulnerability scan report.
- EV042 – System patch and update status.
- EV043 – Vulnerability remediation tracking records.

Purpose
To assess whether organisational systems contain known vulnerabilities due to missing security patches, delayed updates or ineffective vulnerability remediation processes.

No actual organisational evidence is included. This is a simulated portfolio project.
