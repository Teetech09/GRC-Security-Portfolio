R007 – Backup and Recovery Failures: Risk Validation

This folder is reserved for evidence used to validate the identified backup and recovery risk.

Planned Evidence
- EV035 – Backup policy and procedures.
- EV036 – Backup job execution and failure reports.
- EV037 – Disaster recovery and restoration test reports.

Purpose
To assess whether critical organisational data is backed up regularly, whether backup jobs complete successfully, and whether data and services can be restored within defined Recovery Time Objectives (RTO) and Recovery Point Objectives (RPO).

No actual organisational evidence is included. This is a simulated portfolio project.
