R007 – Backup and Recovery Failures: Remediation Verification

This folder is reserved for evidence used to verify remediation of the identified backup and recovery risk.

Planned Evidence
- EV038 – Updated backup policy and configuration.
- EV039 – Backup restoration test results.
- EV040 – Disaster recovery exercise report.

Purpose
To verify that backup controls have been improved, restoration procedures work as expected, and disaster recovery exercises demonstrate the organisation's ability to recover critical systems and data within defined RTO and RPO targets.

No actual organisational evidence is included. This is a simulated portfolio project.
