R004 – Ransomware Attacks: Risk Validation

This folder is reserved for evidence used to validate the identified ransomware risk.

Planned Evidence
- EV017 – Endpoint protection configuration.
- EV018 – Security incident and malware detection logs.
- EV019 – Backup configuration and recovery records.

Purpose
To assess the organisation's exposure to ransomware attacks and determine whether endpoint protection, incident detection and backup controls are adequate.

No actual organisational evidence is included. This is a simulated portfolio project.
